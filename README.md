## 🚀 Installation

### Prerequisites

- **Python 3.10+**
- **Discord Bot Token** with intents: `Members`, `Message Content`, `Server Members`, `Presence`

### Quick Setup

```bash
# 1. Clone the repo
git clone https://github.com/APZXCORE/apzx-gen-bot.git
cd apzx-gen-bot

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure
# Edit .env and config.py (see Configuration below)

# 4. Run
python main.py
```

---

## ⚙️ Configuration

### `.env`

```env
DISCORD_TOKEN=your_bot_token_here
HOST_NAME=APZX Node
```

### `config.py`

```python
PREFIX = "-"
GUILD_ID = 000000000000000000        # Your server ID
OWNER_IDS = [000000000000000000]     # Your user ID
RESTOCK_ROLE_ID = 000000000000000000 # Optional ping role

# Dashboard
DISCORD_CLIENT_ID = ""
DISCORD_CLIENT_SECRET = ""
DASHBOARD_URL = "http://localhost:8080"
DASHBOARD_PORT = 8080
JWT_SECRET = "your_random_secret"

# Vouch
VOUCH_BAN_DURATION = 172800   # 2 days
VOUCH_CHANNEL_ID = 000000000000000000
```

### Discord Bot Intents

Make sure these are enabled in [Discord Developer Portal](https://discord.com/developers/applications):

| Intent | Required |
|---|---|
| `Members` | ✅ |
| `Message Content` | ✅ |
| `Server Members` | ✅ |
| `Presence` | ✅ |

## 🎨 Emoji Setup

All emojis are defined in [utils/emojis.py](utils/emojis.py). The source `.webp` files live in the `emojis/` folder.

### How to Update Emojis

1. **Enable Developer Mode** → Discord Settings → Advanced → Developer Mode
2. **Right-click** any emoji → **Copy ID**
3. **Edit** [utils/emojis.py](utils/emojis.py):

```python
# Before (placeholder)
success = "<a:tickbox_blue:1493631514603159712>"

# After (your custom emoji)
success = "<a:your_tickbox:YOUR_NEW_ID_HERE>"
```

## 💻 Commands

### User Commands

| Command | Description |
|---|---|
| `/fgen <service>` | Generate from Free stock |
| `/bgen <service>` | Generate from Booster stock |
| `/pgen <service>` | Generate from Premium stock |
| `/stock` | View live inventory |
| `/stats` | System diagnostics |
| `/ping` | Check latency |
| `/uptime` | Bot uptime & status |
| `/vouch` | Check vouch status & timer |
| `/history` | Your generation history |
| `/topgen` | Top generators leaderboard |
| `/cstatus` | Toggle requirement monitoring |
| `/help` | Command guide |

### Admin Commands

| Command | Description |
|---|---|
| `/createfgen <name> <type>` | Create Free tier service |
| `/createpgen <name> <type>` | Create Premium tier service |
| `/createbgen <name> <type>` | Create Booster tier service |
| `/deletefgen` | Delete Free tier service |
| `/deletepgen` | Delete Premium tier service |
| `/deletebgen` | Delete Booster tier service |
| `/uploadstock <tier> <service> <file>` | Bulk upload from .txt |
| `/addstock <tier> <service> <items>` | Add stock inline |
| `/restock <tier> <service>` | Announce with role ping |
| `/setcooldown <tier> <seconds>` | Set tier cooldown |
| `/resetcooldown <user> [tier]` | Reset user cooldown |
| `/genlogs [limit]` | View generation logs |
| `/backup` | Backup the database |
| `/ban <user> <reason>` | Permanent ban |
| `/tempban <user> <seconds> <reason>` | Temporary ban |
| `/unban <user>` | Unban user (Owner) |

## 🖥️ Dashboard

Access the web panel at `http://localhost:8080` (or your configured port).

**Features:**
- 📊 Live stock counts & system stats
- 📦 Inventory management (create / add stock)
- 👥 User management & pagination
- ⚙️ Full settings editor (channels, roles, cooldowns, requirements)
- 🔐 OAuth2 login — owner-only access

**Setup OAuth2:**
1. Go to [Discord Developer Portal](https://discord.com/developers/applications)
2. OAuth2 → Add Redirect: `http://localhost:8080/api/auth/callback`
3. Copy **Client ID** & **Client Secret** to `config.py`

## 🔧 Server Setup

After launch, configure these via the **dashboard** or direct database edit:

| Setting Key | Purpose |
|---|---|
| `fgen_channel_id` | Channel for `/fgen` |
| `fgen_role_id` | Role granting Free Gen access |
| `pgen_channel_id` | Channel for `/pgen` |
| `pgen_role_id` | Role granting Premium Gen access |
| `bgen_channel_id` | Channel for `/bgen` |
| `bgen_role_id` | Role granting Booster Gen access |
| `vouch_channel_id` | Vouch verification channel |
| `logs_channel_id` | Bot log channel |
| `restock_channel_id` | Restock announcement channel |
| `restock_role_id` | Role to ping on restock |
| `status_req` | Status text required for free gen |
| `invite_req` | Minimum invites needed |
